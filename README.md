# Debian 13 (Trixie) for ASUS VivoTab Note 8 (M80TA)

Оптимизированный гибридный Live / Install образ дистрибутива **Debian 13 (Trixie) amd64** для планшета **ASUS VivoTab Note 8 (M80TA)**.

Превращает устаревший Windows-планшет 2014 года в стильный карманный кибердек, цифровой блокнот на пассивном пере Wacom EMR или прикроватный терминал мониторинга.

---

## ⚡ Особенности и решенные аппаратные нюансы

| Компонент / Проблема | Решение в данной сборке |
| :--- | :--- |
| **32-битный UEFI (IA32) + 64-битный CPU** | Установлен автономный `grub-efi-ia32` (`BOOTIA32.EFI`) с параметрами `--no-nvram --removable`. **Защищает хрупкий NVRAM Asus от переполнения и окирпичивания**. |
| **Аппаратный баг Bay Trail (зависание в простое)** | В ядро вшит параметр `intel_idle.max_cstate=1`, исключающий падение процессора Z3740 при переходе в глубокие энергосберегающие состояния C6/C7. |
| **Портретная матрица (800×1280) и поворот** | Консоль развернута через `fbcon=rotate:1`. В графике **Plasma Mobile (Wayland)** через `iio-sensor-proxy` автоматически синхронно вращает интерфейс, экранную клавиатуру, тачскрин и перо Wacom. |
| **Wacom EMR стилус** | Работает из коробки с определением 1024 градаций нажатия, ластиком на торце и аппаратным palm rejection (блокировкой ладони). Предустановлен **Xournal++**. |
| **2 ГБ RAM и медленная eMMC** | Включен `systemd-zram-generator` (сжатый zstd-своп на 3 ГБ в памяти с `vm.swappiness=180`). Корневая система развернута на **Btrfs со сжатием `zstd:3`** (экономит до 50% места на 32/64 ГБ eMMC и бережет ресурс флеш-памяти). |
| **Фоновые тормоза KDE** | Полностью отключен прожорливый индексатор файлов KDE Baloo (`baloofilerc`). |
| **Звук Intel SST (ALC5640 / ALC5672)** | Интегрированы актуальные профили `alsa-ucm-conf` и стек **PipeWire + WirePlumber**. |
| **Сетевой доступ и Cyberdeck-режим** | **OpenSSH Server** включен по умолчанию. Планшет сразу анонсирует себя по mDNS как `vivotab-m80ta.local`. |
| **Установка в 1 клик** | На рабочем столе предустановлен скрипт `install-to-emmc`, который безопасно переносит систему с USB-флешки на внутреннюю eMMC с разметкой Btrfs и правильным IA32 GRUB. |

## 🚀 Быстрый старт: Скачивание, запись и запуск

### 1. Скачивание готового образа

Образ собран и готов к загрузке:
- **Файл:** `m80ta-debian13-plasma-mobile.img.xz` (~2.01 ГБ)
- **SHA256:** `e6c18cb28639d433a0fa78768c43158aaa9573d0c261fa5f1a3049106a48b90d`

Команда для скачивания на Mac/ПК:
```bash
scp de-hz-dev-dl-worker:/srv/build-m80ta/output/m80ta-debian13-plasma-mobile.img.xz ~/Downloads/
```

### 2. Запись образа на флешку
Запишите скачанный файл на USB-флешку или MicroSD карту объемом от 8 ГБ:
- **Графически:** Через [BalenaEtcher](https://etcher.balena.io/) или [Raspberry Pi Imager](https://www.raspberrypi.com/software/) (они распаковывают `.xz` автоматически).
- **Консолью (Linux / macOS):**
  ```bash
  xz -dc ~/Downloads/m80ta-debian13-plasma-mobile.img.xz | sudo dd of=/dev/rdiskX bs=4M status=progress conv=fsync
  ```

### 3. Загрузка планшета
1. Подключите записанную флешку к планшету через **Micro-USB OTG переходник** (рекомендуется подключить и USB-клавиатуру через хаб на случай первого входа).
2. Зажмите кнопку **Уменьшения громкости (Volume Down)** и, удерживая её, нажмите **Кнопку включения (Power)**.
3. В появившемся меню загрузки UEFI выберите ваш USB-накопитель.
4. Система запустится в Live-режиме прямо в графическую оболочку Plasma Mobile.

### 4. Проверка периферии в Live-режиме
Перед установкой на диск проверьте:
- Работу сенсорного экрана и стилуса Wacom;
- Подключение к Wi-Fi (через панель Plasma Mobile);
- Звук и регулировку громкости;
- Доступ по SSH с другого компьютера (`ssh vivotab@vivotab-m80ta.local`).

## 💾 Установка на внутреннюю память (eMMC)

Когда вы убедились, что всё работает:
1. Запустите ярлык **Install to eMMC** на рабочем столе (или выполните в терминале `sudo /usr/local/bin/install-to-emmc`).
2. Скрипт отобразит обнаруженный диск `/dev/mmcblk0` и его размер (32 или 64 ГБ).
3. Введите `YES` для подтверждения.
4. Скрипт автоматически:
   - Разметит eMMC в GPT;
   - Создаст раздел ESP FAT32 и Btrfs со сжатием `zstd:3`;
   - Скопирует работающую систему;
   - Сгенерирует правильные UUID в `/etc/fstab`;
   - Установит 32-битный загрузчик `BOOTIA32.EFI` без вызова опасного для прошивки `efibootmgr`.
5. По завершении извлеките флешку и перезагрузите планшет.

## 🛠 Полезные советы для M80TA

### Одновременная зарядка и OTG
У M80TA всего один разъем Micro-USB, через который идет и питание, и данные. Обычный пассивный OTG-кабель отключает подачу внешнего питания.
Чтобы использовать планшет на постоянной основе как кибердек с клавиатурой и зарядкой:
- Используйте **OTG Y-кабель с переключателем режима ACA (Accessory Charger Adapter)** (например, адаптеры для Dell Venue 8 Pro или Lenovo Miix).
- Контроллер питания Intel Crystal Cove в M80TA распознает специфическое сопротивление на контакте ID и переходит в режим питания Host + Charging.

### Легкий веб-браузинг
Тяжелые браузеры (Google Chrome, Electron) быстро исчерпают 2 ГБ RAM. В образ предустановлен:
- **Falkon** — быстрый легковесный браузер на движке QtWebEngine. Идеален для веб-интерфейсов Home Assistant, Grafana, OpenWebUI или чтения документации.

## 🏗 Сборка образа с нуля

Сборка полностью автоматизирована в среде Docker:

```bash
git clone https://github.com/Sin7009/asus-vivotab-m80ta-linux.git
cd asus-vivotab-m80ta-linux

# Запуск сборки в привилегированном контейнере Debian 13
sudo ./build/run-docker.sh
```

Готовый файл и SHA256 контрольная сумма будут сформированы в каталоге `output/`:
`output/m80ta-debian13-plasma-mobile.img.xz`
