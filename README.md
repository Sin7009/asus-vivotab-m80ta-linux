# Debian 13 (Trixie) for ASUS VivoTab Note 8 (M80TA)

Оптимизированный гибридный Live / Install образ дистрибутива **Debian 13 (Trixie) amd64** для планшета **ASUS VivoTab Note 8 (M80TA)**.

Превращает устаревший Windows-планшет 2014 года в стильный карманный кибердек, цифровой блокнот на пассивном пере Wacom EMR или прикроватный терминал мониторинга.

---

## ⚡ Особенности и решенные аппаратные нюансы

| Компонент / Проблема | Решение в данной сборке |
| :--- | :--- |
| **32-битный UEFI (IA32) + 64-битный CPU** | Установлен автономный `grub-efi-ia32` (`BOOTIA32.EFI`) с параметрами `--no-nvram --removable`. **Защищает хрупкий NVRAM Asus от переполнения и окирпичивания**. |
| **Аппаратный баг Bay Trail (зависание в простое)** | В ядро вшит параметр `intel_idle.max_cstate=1`, исключающий падение процессора Z3740 при переходе в глубокие энергосберегающие состояния C6/C7. |
| **Портретная матрица (800×1280) и поворот** | Консоль развернута через `fbcon=rotate:1`. В графике **Plasma Mobile (Wayland)** через `iio-sensor-proxy` автоматически синхронно вращает интерфейс, экранную клавиатуру, тачскрин и перо Wacom. |
| **Wacom EMR стилус** | Работает из коробки с определением 1024 градаций нажатия, ластиком на торце и аппаратным palm rejection (блокировкой ладони). Предустановлен **Xournal++**. |
| **2 ГБ RAM и медленная eMMC** | Включен `systemd-zram-generator` (сжатый zstd-своп на 3 ГБ в памяти с `vm.swappiness=180`). Корневая система развернута на **Btrfs со сжатием `zstd:3`** (экономит до 50% места на 32/64 ГБ eMMC и бережет ресурс флеш-памяти). |
| **Фоновые тормоза KDE** | Полностью отключен прожорливый индексатор файлов KDE Baloo (`baloofilerc`). |
| **Звук Intel SST (ALC5640 / ALC5672)** | Интегрирован стек **PipeWire + WirePlumber**, профили `alsa-ucm-conf` и бинарники DSP **`firmware-intel-sound`** (`fw_sst_0f28.bin`). |
| **Сеть и Wi-Fi** | Включены `wpasupplicant`, `wireless-regdb`, `iw`, `rfkill`, `network-manager`. Поддерживается преднастроенный профиль `files/m80ta-wifi.nmconnection`. |
| **Безопасный SSH для отладки** | Вход строго по публичному SSH-ключу пользователя (`PasswordAuthentication no`, `PermitRootLogin no`, root заблокирован). SSH host keys и `machine-id` уникально генерируются при первом старте через `m80ta-firstboot.service`. `vivotab` имеет `NOPASSWD:ALL` для удобства отладки. |
| **Безопасная установка на eMMC v1.1** | Скрипт `install-to-emmc` аппаратно проверяет тип памяти (`MMC` vs `SD`), запрещает затирание загрузочного носителя, требует точного ввода пути диска и `CONFIRM_DESTROY`, сбрасывает machine-id и валидирует `BOOTIA32.EFI`. |

## ⚠️ ВАЖНО ПЕРЕД НАЧАЛОМ

### 1. Отключение Secure Boot в BIOS
Поскольку кастомный 32-битный загрузчик `BOOTIA32.EFI` не имеет цифровой подписи Microsoft, Secure Boot **обязательно нужно отключить**:
1. Подключите USB-клавиатуру к планшету через OTG-хаб.
2. При включении удерживайте клавишу `Esc` или `F2` (либо зажмите `Volume Down` + `Power` и выберите вход в Setup).
3. Перейдите во вкладку **Security** -> **Secure Boot Configuration**.
4. Установите **Secure Boot** в положение **Disabled**.
5. Нажмите `F10` для сохранения и перезагрузки.

### 2. Резервная копия Windows и калибровок Wi-Fi
Перед полным стиранием eMMC:
- Создайте полный образ памяти планшета (например, через Macrium Reflect или `dd`).
- **Как минимум сохраните каталог `C:\Windows\System32\DriverStore`**: в нем находятся специфичные для вашей ревизии M80TA файлы калибровки Broadcom Wi-Fi (NVRAM `brcmfmac43340-sdio.txt`), которые могут потребоваться в случае проблем с мощностью радиомодуля.

## 🔑 Учетные данные и доступ по SSH

- **Пользователь:** `vivotab`
- **Пароль для sudo:** не требуется (`NOPASSWD:ALL` для отладки)
- **Root:** пароль заблокирован, прямой вход запрещен
- **Автологин в GUI:** включен в сессию **Plasma Mobile**
- **Запасная сессия:** **XFCE4** (доступна при выходе в экран SDDM)
- **SSH доступ:**
  - Вход разрешен **только по SSH-ключу** (пароли и вход root выключены).
  - Уникальные ключи сервера генерируются при первом включении планшета.
  - Подключение по имени mDNS:
    ```bash
    ssh-keygen -R vivotab-m80ta.local 2>/dev/null
    ssh vivotab@vivotab-m80ta.local
    ```

## 🚀 Быстрый старт: Скачивание, запись и запуск

### 1. Скачивание готового образа v1.1
```bash
scp de-hz-dev-dl-worker:/srv/build-m80ta/output/m80ta-debian13-plasma-mobile-v1.1.img.xz ~/Downloads/
```

### 2. Запись образа на флешку
Запишите скачанный файл на USB-флешку или MicroSD карту объемом от 8 ГБ:
- **Графически:** Через [BalenaEtcher](https://etcher.balena.io/) или [Raspberry Pi Imager](https://www.raspberrypi.com/software/).
- **Консолью (Linux / macOS):**
  ```bash
  xz -dc ~/Downloads/m80ta-debian13-plasma-mobile-v1.1.img.xz | sudo dd of=/dev/rdiskX bs=4M status=progress conv=fsync
  ```

### 3. Загрузка планшета
1. Подключите флешку через **Micro-USB OTG переходник**.
2. Зажмите кнопку **Уменьшения громкости (Volume Down)** и, удерживая её, нажмите **Включение (Power)**.
3. В меню UEFI выберите ваш USB-накопитель.
4. Планшет запустится сразу в Live-сессию Plasma Mobile.

### 4. Проверка оборудования
Выполните пошаговое тестирование периферии по чек-листу в файле [TESTING.md](TESTING.md).

## 💾 Установка на внутреннюю память (eMMC)

Когда вы убедились в корректной работе в Live-режиме:
1. Запустите ярлык **Install to eMMC** на рабочем столе (или выполните `sudo /usr/local/bin/install-to-emmc`).
2. Скрипт проверит накопители, отсеет внешние карты памяти MicroSD и выведет список найденных чипов eMMC.
3. Введите точный путь к целевому диску: `/dev/mmcblk0`.
4. Для подтверждения форматирования введите: `CONFIRM_DESTROY`.
5. Скрипт разметит eMMC, клонирует систему, сбросит machine-id/SSH-ключи (чтобы планшет получил свои уникальные идентификаторы) и валидирует загрузчик `BOOTIA32.EFI`.
6. Извлеките флешку и перезагрузитесь.

## 🏗 Сборка образа с нуля

Сборка полностью воспроизводима в Docker:

```bash
git clone https://github.com/Sin7009/asus-vivotab-m80ta-linux.git
cd asus-vivotab-m80ta-linux

# (Опционально) Добавьте ваш публичный SSH-ключ для авторизации:
cp ~/.ssh/id_ed25519.pub files/authorized_keys

# (Опционально) Добавьте домашний Wi-Fi для автоподключения:
# cp files/m80ta-wifi.nmconnection.example files/m80ta-wifi.nmconnection

# Запуск сборки:
sudo ./build/run-docker.sh
```
Готовый образ будет сформирован в `output/m80ta-debian13-plasma-mobile-v1.1.img.xz`.
